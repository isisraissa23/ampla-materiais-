
# AMPLA Materiais para Construção 
Site institucional desenvolvido para a **AMPLA Materiais para Construção**, com o objetivo de apresentar a empresa, seus produtos e facilitar o contato com os clientes.

## Sobre o projeto
O site apresenta:

-  Página inicial
- Informações sobre a empresa
- Catálogo de produtos
- Serviços oferecidos
- Contato pelo WhatsApp
-  Localização da empresa
-  Solicitação de orçamento

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
